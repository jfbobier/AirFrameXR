# AirFrameXR 1.0 (formerly VisionALVR)

**New name.** VisionALVR is now **AirFrameXR**, at the ALVR developers' request: the name and logo suggested an affiliation with the ALVR project that does
not exist. AirFrameXR is an independent wireless-first OpenXR runtime and streamer for NVIDIA GPUs that speaks the ALVR protocol (version 20), so the
existing ALVR headset apps keep working with it. New logo and visual identity (`branding/`).

Upgrading from VisionALVR: unzip next to the old folder and start `AirFrameXR.exe`. A `config\visionalvr.json` copied into the new `config\` folder is
used as the settings file; the launcher's OpenXR runtime button switches your games to the new folder.

Everything in [0.6.1-alpha](v0.6.1-alpha.md), plus:

- **The desktop mirror lets go when a game starts.** A game started while the mirror was on screen could be counted as the mirror, and the headset
  alternated between the two (a flicker). The game now takes the headset, the engine records the mirror's run and then the game's, and the mirror leaves
  within a couple of seconds at the latest. A regression scenario (`e2e_mirror_handover`) covers it.
- **The setup wizard offers the usual refresh rates the headset did not list** (a Quest 3 may not list 120 Hz), with a warning, instead of only the listed ones.
- **Log exports carry the desktop mirror's log and the refresh rates the headset reported**, to make reports easier to read.

Tested on an RTX 5090 with an Apple Vision Pro and a Quest 3. Frame generation needs an NVIDIA RTX GPU (Turing or later). Use at your own risk, see the README.
