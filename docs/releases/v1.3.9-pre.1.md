# AirFrameXR 1.3.9 pre-release 1: an Xbox pad for the desktop mirror

[1.3.8](v1.3.8.md)'s package with one change: the desktop mirror reads an Xbox controller. The host, shim and interface are 1.3.8's unchanged (the version inside the zip still says 1.3.8).

## What is new

- **Desktop mirror: Xbox pad.** Either stick moves the Windows cursor (the stronger one wins), **A** = click, **B** = double click, wherever the cursor is. XInput, loaded at run time; nothing happens when no pad is connected. The pad acts like a physical mouse: the VR beam yields to it until a trigger press or a sweep of the beam takes the cursor back. The controls panel lists it. Details: `docs/DESKTOP_MIRROR.md`.

## What ran, and what did not

`mirrordesktop.exe` builds on the builder (cl, release) and the shipped zip contains it (checked: the XInput call is in the binary). Compile check with clang-cl against the Windows SDK headers: no errors.

**Not run:** the pad on a headset session (stick speed, dead zone, A / B landing on the cursor, XInput reporting while the session has focus); no harness scenario covers the pad; `mirror_check` was not re-run. The bundle is the 1.3.8 bundle with the new `mirrordesktop.exe` swapped in, not a full rebuild.
